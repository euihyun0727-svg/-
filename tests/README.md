# NeuroDesk 기술 수정 검증

저장소 루트에서 Node.js 18 이상으로 실행합니다.

```sh
node tests/neurodesk-regression.mjs
```

외부 패키지 설치 없이 85개 검사를 실행합니다. 실제 index.html의 19개 스크립트를 가벼운 모의 DOM에서 실행하고, 12개 증상 및 20개 질환 경로를 확인합니다.

## 검증한 범위

- 중복 클릭, 답 선택 후 다음/이전, 모드 변경, 새 환자 초기화 시 문진 타이머
- 기존 emergency 표시가 있는 답변의 자동 이동 중단과 의료진 확인 안내
- 재진 악화 또는 새 증상 응답 시 상세 문진 연결, 안정적 재진의 간단 문진 유지
- 무결성 자동진단 전후 AppState 보존
- 단계 전환 후 종이 척도 입력값 유지
- 질환별 안내서 초안과 교육 선택 분리, 재확인과 새 환자 초기화
- 인쇄 준비 중 내용 변경 시 중단, 중복 인쇄 방지, 이미지 준비 실패 처리
- 표준 교육 인쇄의 재확인, 인쇄용 SVG marker 참조 분리
- EMR의 재진 응답/전체 질문 포함과 클립보드 실패 안내
- PNG 참조가 저장소 최상위 파일명과 일치하는지, 인쇄 헤더 CSS 우선순위

## 한계

DOM·타이머·클립보드·이미지 디코딩·window.print는 모의 환경입니다. 실제 이미지 표시, CSS 레이아웃, 브라우저 클립보드 권한, 모바일, 인쇄 미리보기와 A4 페이지 나눔을 검증하지 않습니다. 로컬 Edge 자동화는 브라우저 프로세스 시작 오류로 실행하지 못했습니다. Netlify 배포도 미실시입니다.

애플리케이션의 내장 95개 무결성 검사는 데이터 존재 및 일부 경로 혼입 검사입니다. 이 테스트 85개와 별도이며, 어느 쪽도 임상적 정확성을 인증하지 않습니다.

## 보존한 임상 데이터와 남은 검수

이번 변경에서 NEURO_DATA의 질문·검사·치료·척도·위험신호 원문과 EDUCATION_V2 본문은 변경하지 않았습니다. 디자인과 정적 배포 구조도 유지합니다.

다음 항목은 의료진의 승인된 수정안이 필요합니다.

- 발작 위험신호의 30분 표현과 교육문의 5분 표현 불일치
- 두통 약물복용일수의 5~9일 선택지 누락과 약제별 과용 기준
- ICHD-3, HINTS, TUG, 뇌졸중·돌발난청 시간 표현 등 기존 임상 검수 목록
- 환자 문항의 선택지 보완과 증상별 세부 조건부 분기
- 척도별 공식 판본·사용권, 문항·자동채점·점수 범위 및 단위
- 원내/외부 검사 분류와 추가 질환 경로

응급 안내는 기존 emergency 데이터 표시만 사용합니다. 새로운 응급 기준이나 진단 규칙을 추가하지 않았습니다. 재진 악화/새 증상의 상세 문진 연결도 응급 여부의 자동 판정이 아닙니다.
