# 선택한 B안 적용 — 연결 심볼과 작은 문서 일러스트

기준 main: `354ef7d5a55302a756ba9e8d5e202b43223970ec`. 작업일: 2026-11-03.

## 적용 범위

- 공통 헤더의 CSS N 박스를 연결선 두 개와 안내점을 사용한 새 심볼로 교체하고 NeuroDesk 워드마크를 정리했다. 이는 사용자가 선택한 기존 브랜드 변경이다. 별도 기존 로고 파일은 저장소에서 확인되지 않았다.
- ‘추적관리 및 교육’에 아이보리·네이비·청록 B안 적용. STEP 05 도입부와 174×104 문서 일러스트, 설명·계획/검사 첨부/교육의 세 작업 면, 332px 출력 패널(1100px 이하 320px)을 구성했다. 920px 이하에서는 출력 패널을 아래로 이동하며 일러스트는 850px 이하에서 숨긴다.
- 아이콘은 설명·계획, 검사, 교육, 출력 제목 네 곳에 한정. 24×24 viewBox, 1.75 굵기, 실제 22px. 심볼·일러스트·아이콘은 프로젝트 내부 SVG 파일이며 외부 라이브러리나 다운로드가 없다.
- 작은 구성 미리보기는 현재 작성한 설명/계획, 실제 선택한 교육 제목, 출력 선택한 검사 이미지 제목을 반영한다. 환자 정보나 결과를 만들어 넣지 않는다. 긴 문장은 두 줄로 요약 표시하며 전체 내용은 기존 안내서 미리보기 버튼에서 확인한다. 의사용 메모는 읽어 출력하지 않는다.

## 기능 및 A4 보존

기존 입력 요소/순서/ID, 문진 분기, 임상척도, 교육 문구, 파일 제한/선택/메모/순서/삭제/자원 해제, 확인 조건, 초기화, 출력 생성 함수를 유지했다. 구성 요약은 별도의 화면 요소로 출력 문서나 승인 상태에 영향을 주지 않는다.

`visit-materials.js`에는 invalidation/교육 출력 영역/첨부 목록 갱신 후 요약을 갱신하는 표현 계층 호출 세 곳만 추가했다. `followup-workspace.js`에는 텍스트 기반 구성 요약 렌더러를 추가했다. 사용자 문자열은 textContent로 표시한다. 외부 전송, 저장, 자동 진단/추출 기능을 추가하지 않았다.

index의 인라인 임상 JavaScript와 CSS(기존 인쇄 스타일 포함), 출력 HTML 생성 함수는 기준 코드와 동일하다. 기존 ID 모두 보존하고 중복 없음. 교육용 그림과 검사 이미지의 출력 조건도 기존 생성 함수를 따른다. 새 장식은 no-print 영역과 화면 전용 CSS에 한정하며 별도 인쇄 숨김 규칙도 있다.
