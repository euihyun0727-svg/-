## 검사·치료 비교 및 국내 확인

### 반사성·상황성 실신

유발 상황·전구 증상·회복과 심장성 위험을 대조

- 검사: **12유도 ECG·원인별 검사** — 실신 기본 평가·심장 위험 확인 / 제한: 관행적 EEG·영상·tilt를 모든 실신에 적용 안 함 / 원내 시행/외부 의뢰·수가 확인 필요

비약물: 유발/전구 인지·누워 안전 확보·대항압박법 적합성·수분은 심장/신기능 고려

자동 연결 약물 후보 없음. 원인·전문 평가 후 개별 결정.

추적: 재발·손상·전구/양상 변화·운전/작업 위험 재평가

국내: 품목별 허가·급여 현행 인정기준 미확인

검수: 신경과 전문의 최종 검수 전

### 기립성저혈압 관련 실신

기립 실측·증상·원인으로 혈역학적 사건 평가

- 검사: **앙와위/기립 혈압·맥박** — 증상-혈압 관계와 원인 / 제한: 측정 조건·지속 여부 확인. 자세만으로 확정 안 함 / 원내 시행/외부 의뢰·수가 확인 필요

비약물: 약 검토·느린 기립·낙상 예방·수분/염분 개별 조정

|치료 검토 후보|근거|안전·용량|국내 상태|
|---|---|---|---|
|필요 시 승압제 전문 검토|보존 조치 후 증상성 OH에 원인별 선택.|누운 자세 고혈압·심장/신기능·부종/전해질·병용약 감시. 항고혈압제 자동 중단 안 함. 수치 용량·증량 미확인: 해당 품목 허가사항 검토 후 결정|국내 해당 적응증·허가·급여·공급 미확인. 해외 권고와 구분|

추적: 기립/누운 혈압·증상·낙상·약 반응 추적

국내: 품목별 허가·급여 현행 인정기준 미확인

검수: 신경과 전문의 최종 검수 전

### 심장성 실신 위험 평가

부정맥/구조 심장질환을 우선 확인하는 감별 경로

- 검사: **ECG·빈도에 맞는 장기 심전도·선택 심초음파** — 의심 부정맥/구조 원인 평가 / 제한: 낮은 빈도 사건에 짧은 Holter 음성만으로 배제 안 함 / 원내 시행/외부 의뢰·수가 확인 필요

비약물: 평가 전 운동·운전/위험 작업 안전 계획

자동 연결 약물 후보 없음. 원인·전문 평가 후 개별 결정.

추적: 전문 평가 결과·재발·심장 증상에 따라 조기 추적

국내: 품목별 허가·급여 현행 인정기준 미확인

검수: 신경과 전문의 최종 검수 전

### POTS·기립불내성 평가

만성 기립 증상과 빈맥·OH 부재·다른 원인을 확인

- 검사: **기립 연속/반복 활력·원인 검사** — 필요 프로토콜로 빈맥/OH 및 다른 원인 구분 / 제한: 어지럼 모듈의 단일 혈압 차이 계산기로 POTS 진단 안 함 / 원내 시행/외부 의뢰·수가 확인 필요

비약물: 심장/신기능 고려 수분/염분·압박·단계적 운동을 개별 검토

자동 연결 약물 후보 없음. 원인·전문 평가 후 개별 결정.

추적: 기립 증상·활동/기능·맥박/혈압·동반 질환과 약 내약성 추적

국내: 품목별 허가·급여 현행 인정기준 미확인

검수: 신경과 전문의 최종 검수 전

## 전문의 검수 및 적용 한계

핵심 확인 항목은 공식 진단기준 전문을 대체하지 않습니다. 진단/검사/처방은 자동 생성하지 않으며 의사가 후보를 선택해 안내 초안에 반영합니다. 확인되지 않은 수치 용량·금기·권고 등급은 확정하지 않았습니다.

원내 검사/외부 의뢰 구분은 기관 정보 미확인이므로 확인 필요입니다. 국제 권고와 국내 허가·급여·공급을 분리했습니다. 특정 아도페정의 AD 허가 확인 외 국내 품목·환자별 급여는 미확인이며 약가 등재만으로 급여를 판정하지 않습니다.

질환별 정의/진단 항목의 충분성, 응급 분류·의뢰 기준, 약물 선택·상호작용·특수 환자군, 교육 내용의 적합성은 전문의 최종 검수 전입니다. 공통 PNG는 증상군 참고로 표시하며 새로운 질환에 부정확하게 붙이지 않습니다. 새 경로 SVG는 평가·관리 흐름입니다. 실제 파일을 내장한 단일 HTML이 아니므로 저장소 전체를 내려받아 압축 해제해야 합니다.
