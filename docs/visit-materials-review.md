# 검사 결과 첨부·환자 교육 보강 검토

기준 main: 904aed0d0057ebd5ff676a73db9b8a5591239b75. 기준일 2026-10-27. 별도 브랜치/PR이며 승인 전 main 병합·Netlify 배포를 하지 않습니다.

- index.html: 추가 CSS/데이터/스크립트 연결, 기존 두 출력 함수의 새 출력 엔진 위임.
- clinical/visit-materials.js: 방문 단위 이미지·선택 교육·미리보기·출력.
- clinical/visit-materials.css: 기존 디자인에 맞춘 편집 UI와 흰색 인쇄.
- clinical/patient-education-data.js: 72개 경로의 독립 교육 항목/근거.
- tests/visit-materials.mjs: 새 기능의 실제 실행한 모의 검사.
- tests/remaining-clinical.mjs: 교육 본문 비교 대상을 새 교육 데이터로 갱신. 해당 1개 확인문 외 기존 검사 유지.
- docs/visit-materials-test-results.json: 실행 결과.

두통·어지럼·나머지 질환·척도 runtime 원본을 수정하지 않았습니다. 12개 증상군·72개 경로·현재 화면 테마·SVG/PNG 참조를 유지했습니다. 새 교육 UI가 기존 추적 입력을 덮어쓴 회귀를 발견해 동적 추적 패널 노드를 보존하도록 수정하고 전체 검사를 재실행했습니다.

## 사용 방법

1. 의사용 데스크에서 증상·질환을 선택하고 5단계 추적관리/교육으로 이동합니다.
2. 검사 결과·첨부자료에서 JPG/PNG/WebP 캡처를 추가합니다. 이름·등록번호 등은 첨부 전에 사용자가 제거/확인합니다. 자동 판독·비식별화는 없습니다.
3. 검사 분류·검사일(선택)·제목·환자 설명·화면 전용 의사 메모를 입력합니다. 확대·위/아래 이동·삭제가 가능합니다.
4. 필요한 이미지만 안내서 포함을 체크하고 교육 항목을 선택합니다. 첫 방문 경로에서는 의미/생활관리/긴급 변화 3개 핵심 항목이 기본 선택됩니다. 이후 경로 변경에는 이전 선택을 지우며, 핵심 교육 선택 버튼으로 새 경로의 권장 항목을 다시 선택합니다.
5. 선택 내용 미리보기에서 제목·이미지·설명·교육을 확인하고 의료진 확인 후 안내서를 인쇄/PDF 저장합니다. 기존 교육 인쇄 버튼도 같은 선택 기반 출력 엔진을 사용합니다.

이미지는 최대 8장, 파일당 8 MB, 합계 32 MB, 파일당 4천만 화소입니다. 확장자·MIME·파일 서명과 실제 브라우저 디코딩 성공을 확인한 뒤 추가하는 코드입니다. 개발 검사는 디코더를 모의 처리했으므로 실제 브라우저 디코딩 시험을 의미하지 않습니다. 중복은 파일명·크기·수정시각으로 식별하며 내용 해시 중복 검사는 아닙니다.

## 상태·보안 경계

- 현재 방문 메모리/Object URL만 사용. 서버·AI 전송과 localStorage/IndexedDB 저장 없음.
- 새로고침/창 닫기 시 복원되지 않으며, 별도의 환자 기록 관리 프로그램이 아닙니다.
- 증상·질환 변경 시 첨부 원본과 메모는 유지하고 이미지/교육 출력 선택·승인을 지웁니다. 이전 경로로 돌아와도 선택 복원 안 함.
- 새 환자 시작 시 파일·메모·선택·승인·출력·Object URL 초기화. 업로드 중 초기화 후 늦게 완료된 파일도 무시/해제.
- 의사 메모는 편집 화면에만 있고 환자 교육/안내 미리보기·출력·EMR로 자동 전달하지 않음.
- 입력은 HTML 이스케이프하여 표시. 외부 출처 링크는 명시적 클릭만으로 열고 noopener/noreferrer 사용.
- 첨부 추가/완료·설명·메모·순서·출력 선택 변경 시 재확인 필요. 출력 중 변경/새 환자 전환 시 이전 출력 취소.

## 출력

오늘의 설명/검사·치료 계획 → 선택 첨부와 설명 → 선택 질환 교육·기존 그림 → 추적/주의사항 순서입니다. 미리보기와 인쇄는 같은 HTML 생성기를 사용합니다. 의사 메모는 생성기에 포함되지 않습니다.

흰색 배경을 명시하고 첨부마다 별도 페이지를 시작합니다. 이미지 비율을 유지합니다. 세로로 아주 긴 캡처와 긴 설명의 실제 페이지 분할·가독성은 검증하지 못했습니다. 긴 결과표는 여러 읽기 쉬운 캡처로 나눠 첨부하는 것이 좋으며 실제 A4 출력 검수가 필요합니다.

## 교육 보강과 한계

72개 경로, 총 601개 항목(정의/증상/검사/치료/생활/약물/추적/긴급 변화 + 해당 경로의 보호자 안내). 질환·증후군·응급 감별 경로를 구분하고 전조/빈도 등 기존 진단 계층은 바꾸지 않았습니다. NPH·파킨슨·전정성 보행 등은 공통 근거를 공유하되 선택 상태는 경로별로 섞이지 않습니다.

교육은 핵심을 먼저 표시하고 상세는 펼침으로 제공합니다. 접힘 상태와 출력 선택은 독립적입니다. 기본 핵심 외 항목은 의사가 추가 선택해야 출력됩니다. 위험신호 원본 진료 검토 영역은 숨기지 않습니다.

자가 증량/중단·일괄 수분/염분 목표·효과 보장·국내 미확인 허가/급여 주장은 추가하지 않았습니다. 발작 5분 기준 등 확인된 응급 기준만 사용했습니다. 전문의 최종 검수 전 표시를 화면·선택 출력에 유지합니다. 일반 의료 정보가 개인 진단을 확정하는 것으로 표현되지 않게 했습니다.

출처 등록은 81개 ID, 고유 URL 65개입니다. 새로 직접 읽은 NHS 환자정보 10개와 기존 임상 모듈에 실제 열람 기록이 있는 지침·합의문·논문을 재사용했습니다. 후자의 원문을 이번에 모두 새로 열람한 것으로 표시하지 않았고 본문/초록/공식 검색 본문 등의 기존 접근 한계를 유지합니다. NHS의 일부 2022~2023년 정보는 최신 치료지침이 아니라 생활교육 보조 자료입니다. 영국 운전·응급 연락·보험 제도를 국내 기준으로 옮기지 않았습니다.

미완료/검토 필요: 전체 교육의 신경과 전문의 검수, 개별 환자용 표현/분량 검수, 실제 검사 캡처 가독성·A4 페이지 배치, 실제 모바일·키보드 접근성. 모든 질환의 최신 약제 비교나 국내 허가·급여를 새로 검증한 작업은 아닙니다. 기존 의사 참고 콘텐츠/원내 검사 시행 상태는 유지했습니다.
