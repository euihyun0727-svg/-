# NeuroDesk 제품 디자인 v1

스타트업 서비스처럼 정돈된 화면을 요청한 데 따라 기존 main 2fca75d974257da16f2738255427596bb968396f에서 화면 스타일만 변경했습니다.

## 변경

- index.html의 마지막 head에 product-theme.css 이름의 화면 전용 inline style을 추가했습니다. 별도 CSS 다운로드나 폰트 CDN은 없습니다.
- 밝은 회색 바탕·화이트 카드·인디고 주색·짙은 본문색, N 모노그램, 둥근 카드/버튼/상태 표시로 통일했습니다.
- 시작 화면, 문진 옵션, 의사용 5단계 탭, 검사·치료·근거 펼침, 척도, 교육·안내서 편집 화면에 공통 스타일을 적용했습니다.
- 환자 문진 글씨와 터치 영역을 충분히 유지하고 1050/800/560px 구간 반응형 규칙, 키보드 포커스, 모션 감소 설정을 포함했습니다. 이는 코드 확인이며 실제 기기 검증은 아닙니다.

## 기능·인쇄 보존

추가한 media=screen style을 제거하면 기존 index.html과 바이트 단위로 일치함을 확인했습니다. HTML 구조, DOM ID, 이벤트, 스크립트, 임상 문구, 원래 인쇄 CSS를 변경하지 않았습니다. 두통·어지럼·척도 runtime 9개 파일의 SHA256 보존을 확인했습니다. 사진·SVG 파일 참조도 기존 HTML 그대로입니다.

화면 전용이므로 새 CSS는 인쇄 미디어에 적용되지 않습니다. 실제 A4 인쇄 모양은 시험하지 않았습니다.

## 앱 전환과의 관계

기존 웹 동작과 분리된 색·간격·모서리 토큰으로 정리했습니다. 이번 작업에서 PWA·로그인·서버·환자 데이터 저장 기능은 추가하지 않았습니다. 단일 HTML에 모든 자산이 내장된 앱이 아니므로 clinical/, scales/, PNG가 포함된 전체 저장소를 사용해야 합니다.
