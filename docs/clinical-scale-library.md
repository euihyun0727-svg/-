# 한국어 문항으로 직접 시행하는 임상척도

기존 의사용 데스크 4단계에서 척도를 고르면 전체 질문과 응답 선택지가 먼저 표시됩니다. 의료진은 환자에게 원문을 읽고 환자가 선택한 응답을 입력합니다. 4AT는 원래 의료진 평가 방식입니다.

## 제공 도구와 판본

|도구|채점 문항|총점|판본|
|---|---:|---:|---|
|PHQ-9|9|0–27|INfORM 한국어 27Oct2019|
|PHQ-2|2|0–6|위 PHQ-9의 앞 2문항 · 공식 매뉴얼 구성|
|GAD-7|7|0–21|INfORM 한국어 27Oct2019|
|GAD-2|2|0–6|위 GAD-7의 앞 2문항 · 공식 매뉴얼 구성|
|PHQ-4|4|0–12|INfORM 한국어 27Oct2019 · 불안 2문항 먼저|
|PHQ-8|8|0–24|위 PHQ-9에서 9번을 제외 · 공식 매뉴얼 구성|
|4AT|4|0–12|공식 한국어 v1.2|

PHQ-9·GAD-7·PHQ-4에는 원본의 비채점 일상 기능 질문도 제공합니다. PHQ-4는 불안과 우울 소척도를 분리해 표시합니다. PHQ-8은 자해 문항이 없어 자해·자살 위험을 확인하는 검사로 쓰지 않습니다.

## 확인한 이용 근거

- INfORM 공식 한국어 목록: https://inform-iadr.com/index.php/tmd-assessmentdiagnosis/dc-tmd-translations/
- 한국어 원문: https://inform-iadr.com/wp-content/uploads/2024/03/DC-TMD-Korean-Assessment-Instruments_2019_10_27.pdf
  - 한국어 번역자 Jin-Woo Chung·Ji-Woon Park, 컨소시엄 승인 27Oct2019.
  - 인쇄 쪽 번호 p.48(PHQ-4), p.50(PHQ-9), p.52(GAD-7)의 해당 한국어 페이지에 복제·번역·표시·배포 허용 문구가 함께 표시됨.
  - 배포가 임상 검증을 보증하지 않는다는 원문 설명을 유지해 구분함.
- Pfizer 권리자 안내: https://www.phqscreeners.com/select-screener
- Pfizer 이용 조건: https://www.phqscreeners.com/terms
- 채점·단축형 구성 매뉴얼: https://www.phqscreeners.com/images/sites/g/files/g10016261/f/201412/instructions.pdf
  - p.3·6·7의 관련 문항 구성·합산·범위·해석을 근거로 함. 한국어 번역에서 관련 항목을 골라 단축형을 구성하는 것을 명시적으로 설명함.
- 4AT 공식 한국어: https://www.the4at.com/4at-korean
- 4AT 이용 조건: https://www.the4at.com/attribution
- 4AT 채점: https://www.the4at.com/userguide

전자 입력·자동 합산 UI만 추가했습니다. 문항·응답 선택지·배점은 임의 번역하거나 수정하지 않았습니다. 인쇄 줄바꿈과 체크 상자 지시는 화면에 맞게 조정하고 변경을 표시했습니다. 원본 출처·번역자·저작권·조건 링크를 화면에 유지합니다.

INfORM PDF는 텍스트 확인을 완료했지만 스크린샷 도구가 이미지를 반환하지 않아 시각 대조는 완료하지 못했습니다. 원래 Pfizer 한국어 PDF 주소는 접근 실패했으며 해당 판본을 추정 복원하지 않았습니다. 이 구현은 INfORM 배포 판본입니다. 다른 한국어 검증판·국가건강검진 판본과 동일하다고 주장하지 않습니다.

## 제외 도구

기존 85개 중 PHQ-9·PHQ-2·GAD-7·4AT를 남기고, PHQ-4·GAD-2·PHQ-8을 추가하여 총 7개입니다. 나머지 81개는 목록·검색과 배포용 척도 카탈로그에서 삭제했습니다. 구형 증상별 scales 배열도 비워 중복 척도 정보가 남지 않게 했습니다. 검사·치료·교육 자료 안의 임상적 척도 언급은 기존 기능 보존 범위로 유지합니다.

문항 없는 제외 판단·접근 결과만 docs/scale-exclusions.json에 기록합니다. 직접 읽지 못한 약관은 미확인으로 남겼으며, 제외가 척도 자체의 불법성을 뜻하지 않습니다. 특히 MRC 영문 원척도는 OGL 허용을 확인했으나 임의 번역 금지 원칙과 한국어 판본 확인 기준에 따라 제외했습니다.

## 채점과 데이터

- 모든 채점 문항이 응답된 경우에만 합산하며 누락·잘못된 값·희소 배열을 0점으로 처리하지 않습니다.
- PHQ-9 9번 응답이 1점 이상이면 나머지 응답이 비어도 의사의 직접 면담 확인 표시가 나옵니다. 총점으로 위험도를 확정하지 않습니다.
- 비채점 일상 기능 질문은 합산하지 않습니다.
- 척도별 응답을 분리하며 척도 이동·단계 이동 후 복원합니다. 새 환자·새로고침 시 초기화합니다.
- 응답·점수는 AppState 메모리에만 유지합니다. localStorage에는 척도 ID 즐겨찾기와 종이 보유 설정만 저장합니다.
- 원내 보유 응답은 PHQ-9 보유로 유지합니다. 보유한 종이의 정확한 번역판이 이 전자 판본과 같은지는 별도 확인이 필요합니다.
- 외부 API·환자 데이터 전송·설문 자동 다운로드 없음.

## 검증

실행: Node 18 이상에서 `node tests/scale-library.mjs`.

- 척도 검사 594개 통과: 문항별 배점, 모든 가능한 총점, 경계·결측·범위 오류, PHQ-4 소척도, PHQ-9 부분 응답 경고, 비채점 질문, 척도/단계 이동·초기화, 검색·삭제 도구 차단, 출처 링크 속성, 저장 차단/손상, 권리·언어·판본 게이트.
- 4AT 선택 조합 54개 전체 통과.
- 기존 회귀 검사 85개 통과: 12개 증상군·20개 질환 경로 등. 구형 척도 전용 메타데이터 외의 NEURO_DATA 전체 데이터는 변경 전과 동일함을 확인.
- 실제 브라우저 화면·모바일·키보드·접근성·PDF 시각 대조·실제 PNG/클립보드/A4 인쇄·Netlify 배포는 미검증. 모의 DOM의 이미지·클립보드·인쇄는 대체 구현입니다.
- 진료 중 컴퓨터 조작 금지 요청에 따라 사용자 화면·브라우저를 조작하지 않았습니다.
