## 4AT 한국어 전자화 근거

- 공식 한국어 배포: https://www.the4at.com/4at-korean
- 한국어 v1.2 PDF: https://www.the4at.com/wp-content/uploads/2026/07/4AT_Korean_version.pdf
- 현행 이용 조건: https://www.the4at.com/attribution
- 공식 채점: https://www.the4at.com/userguide
- 라이선스: https://creativecommons.org/licenses/by/4.0/

공식 사이트는 복제·공유·각색과 상업적 사용을 CC BY 4.0 조건으로 허용하며 전자 의무기록 통합도 안내합니다. 한국어 배포 페이지는 같은 공식 사이트에 연결되어 있습니다. PDF에 별도 제외 또는 제3자 제한 표시는 확인되지 않았습니다.

4개 항목의 질문·선택지·점수를 원본 PDF 텍스트와 대조했습니다. 웹 UI와 자동 합산으로 전환하고 개인정보 기입란은 제외했습니다. 번역을 새로 만들지 않았습니다. 원 개발자의 저작권·CC BY 링크·변경사항·면책을 화면에 표시합니다. 번역자는 원본에 별도 표기가 없어 ‘확인 필요’입니다. 한국어판이 공식 배포된다는 사실과 별도 임상 타당도 연구가 검증됐다는 주장은 구분합니다. 이 전자 구현의 별도 임상 검증은 미실시입니다. PDF 시각 검증은 완료하지 못했으며 텍스트를 사용했습니다.

공식 사이트에서 일반 복제·표시·배포와 번역판에 관한 허용 안내를 확인했습니다:
https://www.phqscreeners.com/select-screener

공식 사용 설명서의 범위와 해석 구간은 확인했습니다:
https://www.phqscreeners.com/images/sites/g/files/g10016261/f/201412/instructions.pdf

그러나 한국어 원본 파일을 직접 열어 판본·문구·권리 표시를 대조하는 데 실패했습니다. 따라서 원문 문항을 삽입하지 않고 C로 유지했습니다. 다른 사이트의 한국어 문항을 복사하거나 AI로 번역하지 않았습니다. 종이 총점의 범위 검증·영문 중증도 구간만 공식 매뉴얼 기준으로 제공합니다. 한국어판의 별도 진단 절단값이나 보험 인정기준으로 제시하지 않습니다.

## 출처·정보의 확인 수준

scales/catalog.js와 docs/scale-rights.json에 각 도구의 판단 근거 URL과 접근 상태를 기록합니다.
- 원문을 읽은 권리자 문서
- 전문기관의 메타데이터 참고자료
- 공식 출처 후보/검색 출발점
- 검색 결과만 확인했거나 본문 접근 실패

이 네 수준을 구분합니다. ePROVIDE 일부 페이지는 동적 본문을 읽지 못했습니다. NIHSS 공식 자료와 Oxford 일부 자료는 403이었습니다. 원문을 확인하지 못한 약관을 ‘확인 완료’로 표시하지 않았습니다. 항목 수·시간·한국어 검증판·보험 수가 등 검증되지 않은 필드는 ‘확인 필요’로 남겼습니다. 따라서 이 목록은 85개 도구 모두의 법적·임상적 검토가 완료됐다는 의미가 아닙니다.

## 원내 보유와 저장

사용자 확인: MMSE·PHQ-9만 보유, 그 외 미보유. MMSE의 정확한 판본과 K-MMSE/MMSE-2는 구분합니다.
보유는 구입·복제·전자화·청구의 허가를 대신하지 않습니다.

점수·4AT 응답은 기존 AppState.scaleScores 메모리에만 있습니다. 새 환자 초기화 또는 새로고침 시 지워집니다. 브라우저 localStorage에는 척도 ID로 구성한 즐겨찾기와 보유/미보유 설정만 허용합니다. 환자 식별 입력란·점수 저장·자동 전송·문항 자동 다운로드 기능은 없습니다. 저장 차단/손상 시 현재 창에서 동작하도록 처리합니다.

## 실행·배포

index.html과 이미지 12개, scales 폴더를 함께 유지하세요. 단일 HTML만 복사하면 새 라이브러리는 로드되지 않습니다. 외부 라이브러리·CDN·API는 필요하지 않습니다. 로컬 file://와 정적 호스팅을 위한 일반 script/link 경로를 사용합니다. 실제 Netlify 배포와 로컬 브라우저 조합 검증은 미실시입니다.

## 재현 가능한 테스트

Node.js 18 이상, 저장소 루트:

```sh
node tests/scale-library.mjs
```

기존 회귀 85개 + 척도 기능 231개 통과. 척도 검사에는 4AT 가능한 선택 조합 54개 전부, 미응답·유효성·권리 차단·검색·분류·상세·링크 속성·즐겨찾기·보유표시·메모리 초기화·점수 저장 배제가 포함됩니다.

DOM·이미지 디코딩·클립보드·window.print는 모의 환경입니다. 실제 브라우저 UI, 외부 출처 새 탭 이동, 저장 설정의 브라우저별 동작, 모바일, 실제 A4 출력, Netlify 배포는 테스트하지 않았습니다. Windows 화면 도구는 현재 URL을 확인하지 못해 중단됐으며, 사용자의 진료 중 컴퓨터 사용 금지 요청 이후 UI 조작을 하지 않았습니다.
