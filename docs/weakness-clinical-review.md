## 전문의 검수 및 적용 한계

핵심 확인 항목은 공식 진단기준 전문을 대체하지 않습니다. 진단/검사/처방은 자동 생성하지 않으며 의사가 후보를 선택해 안내 초안에 반영합니다. 확인되지 않은 수치 용량·금기·권고 등급은 확정하지 않았습니다.

원내 검사/외부 의뢰 구분은 기관 정보 미확인이므로 확인 필요입니다. 국제 권고와 국내 허가·급여·공급을 분리했습니다. 특정 아도페정의 AD 허가 확인 외 국내 품목·환자별 급여는 미확인이며 약가 등재만으로 급여를 판정하지 않습니다.

질환별 정의/진단 항목의 충분성, 응급 분류·의뢰 기준, 약물 선택·상호작용·특수 환자군, 교육 내용의 적합성은 전문의 최종 검수 전입니다. 공통 PNG는 증상군 참고로 표시하며 새로운 질환에 부정확하게 붙이지 않습니다. 새 경로 SVG는 평가·관리 흐름입니다. 실제 파일을 내장한 단일 HTML이 아니므로 저장소 전체를 내려받아 압축 해제해야 합니다.
