## 검사·치료 비교 및 국내 확인

### 만성 불면장애

수면 기회가 있어도 잠·낮 기능이 지속적으로 불편한지 확인

- 검사: **수면일지·원인 면담** — 양상과 수면 기회/낮 기능 확인 / 제한: 관행적 PSG가 모든 불면에 필수는 아님 / 원내 시행/외부 의뢰·수가 확인 필요

비약물: CBT-I 우선(A): 단순 수면위생만으로 대체하지 않음 / 수면 제한 등은 졸림·양극성/발작 위험 등 개인 안전을 고려해 지도

|치료 검토 후보|근거|안전·용량|국내 상태|
|---|---|---|---|
|필요 시 불면 약물 단기/개별 검토|European 2023: CBT-I 불충분 시 약물 선택.|진정·낙상·인지·의존/금단·호흡·병용약·임신/고령 검토. 장기 동일 처방 자동화 안 함. 수치 용량·증량 미확인: 해당 품목 허가사항 검토 후 결정|국내 해당 적응증·허가·급여·공급 미확인. 해외 권고와 구분|

추적: 수면/낮 기능·CBT-I 실행·부작용·약 지속 필요 재평가

국내: 품목별 허가·급여 현행 인정기준 미확인

검수: 신경과 전문의 최종 검수 전

### 폐쇄성 수면무호흡증(OSA)

호흡 사건의 객관 검사와 졸림·동반질환을 통합 평가

- 검사: **PSG / 대상에 맞는 HSAT** — 객관적 호흡 진단 / 제한: 중요 심폐/신경근·뇌졸중·오피오이드·심한 불면 등은 PSG 적합성 검토 / 원내 시행/외부 의뢰·수가 확인 필요

비약물: 체중/자세·음주/진정제·운전 위험 조정 / 양압기 교육·마스크/비강 불편 지원

|치료 검토 후보|근거|안전·용량|국내 상태|
|---|---|---|---|
|PAP/CPAP·APAP 검토|AASM: 과다 졸림 OSA에 PAP 강한 권고.|기기 방식·설정·적합성·잔여 사건/사용시간은 수면 전문 평가. 압력을 자동 산출하지 않음. 수치 용량·증량 미확인: 해당 품목 허가사항 검토 후 결정|국내 해당 적응증·허가·급여·공급 미확인. 해외 권고와 구분|

추적: 사용시간·잔여 사건·졸림·운전 안전·마스크/비강 불편 평가

국내: 품목별 허가·급여 현행 인정기준 미확인

검수: 신경과 전문의 최종 검수 전

|철 보충 선택|철 상태에 맞는 제형별 권고가 다름.|수치·원인·철 과잉·주입 반응과 제품 허가 확인. 임의 정량 보충 안 함. 수치 용량·증량 미확인: 해당 품목 허가사항 검토 후 결정|국내 해당 적응증·허가·급여·공급 미확인. 해외 권고와 구분|

## 전문의 검수 및 적용 한계

핵심 확인 항목은 공식 진단기준 전문을 대체하지 않습니다. 진단/검사/처방은 자동 생성하지 않으며 의사가 후보를 선택해 안내 초안에 반영합니다. 확인되지 않은 수치 용량·금기·권고 등급은 확정하지 않았습니다.

원내 검사/외부 의뢰 구분은 기관 정보 미확인이므로 확인 필요입니다. 국제 권고와 국내 허가·급여·공급을 분리했습니다. 특정 아도페정의 AD 허가 확인 외 국내 품목·환자별 급여는 미확인이며 약가 등재만으로 급여를 판정하지 않습니다.

질환별 정의/진단 항목의 충분성, 응급 분류·의뢰 기준, 약물 선택·상호작용·특수 환자군, 교육 내용의 적합성은 전문의 최종 검수 전입니다. 공통 PNG는 증상군 참고로 표시하며 새로운 질환에 부정확하게 붙이지 않습니다. 새 경로 SVG는 평가·관리 흐름입니다. 실제 파일을 내장한 단일 HTML이 아니므로 저장소 전체를 내려받아 압축 해제해야 합니다.
