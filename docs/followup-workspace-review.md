# 추적관리 및 교육 작업 공간 리디자인

기준: main `159a6ca0fb6661ae64b0ffcfdcaffe1582e33943`. 검토일: 2026-11-03.

## 변경

- 5단계 화면만 넓은 흰 편집 면과 252px 출력 보조 영역으로 재배치. 720px 이하에서는 세로 배치.
- 기존 다섯 안내 입력 → 첨부 → 교육 선택 순서. 추적 계획·교육 상세·기전 그림은 같은 본문 아래 유지.
- 같은 입력 노드와 이벤트를 이동한다. 파일 선택, 설명, 메모, 선택 상태, 미리보기, 두 출력 승인/버튼의 기존 핸들러를 사용한다.
- 교육 승인 노드는 재렌더링 시 새로 생성되므로 기존 노드를 제거한 후 새 노드를 출력 영역으로 옮긴다. 중복 ID를 방지한다.
- 상단 5단계 명칭/클릭 동작 유지. 활성 단계에 `aria-current=step` 추가. 다른 화면으로 전환하면 기존 테마 복원.
- 사진은 기본 제외. 새 라이브러리·프레임워크·네트워크 전송·저장 기능 없음.

## 보존 범위

임상 데이터·교육 문구·환자 문진·척도 계산·인쇄 문서 생성은 변경하지 않는다. `visit-materials.js`에는 교육 렌더링 전후의 배치 호출 두 곳만 추가한다. `followup-workspace.css` 전체가 `@media screen` 안에 있고 index의 링크도 `media=screen`이다. 기존 흰 A4 스타일, 그림 및 검사 첨부 이미지 출력 설정을 그대로 사용한다. 보조 영역과 새 페이지 헤더는 `no-print`이다.
