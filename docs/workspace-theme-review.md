| 무결성 검사 모달 | 같은 색·서체·모서리 체계 적용. 검사 실행 로직 그대로 |

사진·그래프·가짜 수치·새 기능은 추가하지 않았다. 환자 화면은 18px 전후 이상을 중심으로, 의사용 본문은 16px 전후로 구분했다. 긴 비교표는 기존 가로 스크롤 영역을 보존한다.

## 코드 및 출력 보존

- `index.html`: 기존 요소의 정적 래퍼/클래스와 화면 전용 CSS 링크만 변경.
- `clinical/workspace-theme.css`: 전체가 `@media screen`이며 링크도 `media=screen`이다. A4 생성 및 인쇄 CSS는 수정하지 않음.
- 기존 70개 정적 ID 모두 보존, 중복 없음. 환자 선택 화면의 입력·버튼 속성과 라벨 보존.
- index의 모든 인라인 JavaScript와 인라인 CSS, 이미지 태그는 기준 main과 동일.
- 기준 main의 로컬 JS/CSS/검사 데이터 등 39개 파일의 Git blob SHA 일치 확인. 기존 파일의 임상 코드·교육·그림·척도 데이터는 변경하지 않았다.
- 새 라이브러리, 프레임워크, 저장소, 네트워크 요청, 이미지 전송 없음.

## 확인 한계

위 검사는 Node VM/모의 DOM이며 CSS를 실제 렌더링한 결과가 아니다. 이미지 디코딩·클립보드·window.print는 모의 처리다.

실제 데스크톱/모바일 글자 잘림·버튼 배치, 네이티브 파일 선택/이미지 디코딩, A4 시각적 페이지 나눔/프린터, OS 클립보드, Netlify 운영 화면은 NOT TESTED다. 앞선 작업에서 격리 헤드리스 Edge가 Crashpad/pipe 오류로 종료되어 이 환경에서 화면을 얻지 못했다. 사용자의 열린 브라우저·화면·마우스를 조작하지 않는다.
